# Breach Response Plan

This guide describes the steps to take if a data breach or security incident is suspected.

1. **Identification** – Confirm the incident and determine the scope and affected systems.
2. **Containment** – Isolate compromised components to prevent further exposure.
3. **Assessment** – Investigate logs and gather evidence to understand impact and root cause.
4. **Notification** – Inform affected users and stakeholders as soon as possible.
5. **Remediation** – Patch vulnerabilities, rotate credentials and restore services.
6. **Review** – Document lessons learned and update this plan and security controls.

All incidents should be reported to the project maintainers immediately for coordination.
